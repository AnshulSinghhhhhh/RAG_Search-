# Synthetic search playground

Index `inbox/`, not this entire directory. `scenarios.json` contains expected-answer filenames and stays outside the searchable corpus.

- `screenshots/capture_001.png`: white sneaker, INR 2999.
- `screenshots/capture_001_copy.png`: byte-identical duplicate; should reuse all embeddings.
- `screenshots/capture_002.png`: only the price changes to INR 2499; changed-region OCR must preserve that digit change.
- `screenshots/capture_003.png`: green sneaker, a separate visual memory.
- `screenshots/capture_004.png`: database error screenshot with an exact error code.
- `screenshots/capture_005.png`: Jaipur weekend plan.
- `receipts/`: fictional cafe/bookshop receipts with exact totals and invoice numbers.
- `notes/`: meeting ownership and a camping packing list.
- `voice/`: synthesized English cafe and meeting memos; run actual speech recognition, never index a ground-truth transcript instead.

Images are original geometric/text fixtures generated by `scripts/generate_playground.py`. They are not photographs or actual receipts. WAVs are generated by the operating system's local speech synthesizer from original fictional scripts in that generator. No personal data is included. The decorative waveform in the UI is not measured audio amplitude.

The generator dates the white-sneaker family to the previous calendar month so temporal queries are reproducible when regenerated. Regenerating changes file times; use `brain index playground/inbox --force` afterward.

Try queries from `scenarios.json`, inspect actual sources, compare the changed price, and check activity statistics for duplicate reuse and OCR crop area. Also test deleting/moving a copied sample and running `brain prune`.
